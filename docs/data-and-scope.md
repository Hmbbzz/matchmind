# Data and technical notes

The bundled sample uses historical event and tracking records with fictional team display names. It is a simulated replay; the display names do not change the underlying records into synthetic data. Provenance and distribution details are retained in [third-party notices](../THIRD_PARTY_NOTICES.md) and [replay information](../public/DATA_NOTICE.md).

Eligible movement is a bounded observation. It does not establish a player's intent, prove that no touch occurred, or demonstrate a tactical cause. Estimates remain estimates. Sample assets are bundled with the client, so viewing-cutoff presentation is not raw future-data isolation.

Default local operation uses Match facts and needs no live model request. Local reproduction, a real Azure model response, and hosted judge access are separate checks. The local development sign-in is a fixture, as described in the [run instructions](../README.md#run-locally).

The 3D replay builds on [soccerviewer](https://github.com/andrewRowlinson/soccerviewer). Its original licence and third-party notices are preserved with both the customised source and bundled runtime.
